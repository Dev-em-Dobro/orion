Os prompts prontos, num passo a passo.

O template cobre o comum, o prompt cobre o resto. Quando o nicho do cliente não está na galeria, você gera o que falta. Escolha o prompt certo, clique em copiar e cole no Claude Code (ou lovable, Cursor, Codex). Você nunca fica na mão.

1

Preencha as variáveis

Só o que você sabe (nicho, nome, cidade, WhatsApp). O que não souber, deixe vazio: o prompt manda a IA não inventar.

2

Copie e cole numa conversa nova

Botão "Copiar prompt" no card. Cola inteiro no Claude Code e deixa gerar.

3

Rode os follow-ups

Cada guia tem os ajustes finais. É onde "site ok" vira "site que fecha cliente".

As 5 regras que valem pra todo prompt (padrão da marca)

  • Fonte Ubuntu como padrão.
  • Sem travessão em nenhuma copy.
  • Não inventar fato do cliente: o que faltar vira placeholder.
  • Sem promessa não comprovável ("aumente 300%").
  • Resultado do cliente acima de tudo: o site é o meio.

01
Prompt-mestre testado

Gerar um site do zero

O nicho do cliente não tem template pronto. Resolve 80% dos casos e sai um index.html pronto pra mostrar.

02
Sua vitrine testado

Gerar o seu portfólio

Você ainda não tem portfólio pra mostrar nas abordagens. É o do Bloco 5.5. Portfólio é prova de capacidade, não histórico de clientes.

03
O caminho mais rápido guia

Adaptar um template pro cliente

O nicho tem template na galeria e você quer adaptar em vez de gerar do zero. Adaptar não é só trocar o nome: é nome, cor, copy e provas.

04
O texto que vende guia

Copy do site

O site existe mas o texto está genérico. Headline, seções, provas e CTA no tom de quem resolve, não de quem vende.

05
A porta mais fácil guia

Página de captura / agendamento

O cliente não precisa de site inteiro, precisa de uma página que capte lead ou marque horário. O entregável mais rápido de vender.

06
O gancho de venda guia · 2 prompts

Otimizar performance e responsivo

Garantir que o site está rápido antes de entregar. E o segundo prompt: o site do lead está lento e você usa isso como gancho. "Dinheiro saindo pela porta."
