Setup do Orion

Configure o Orion sem travar.

O Orion precisa de uma chave de API do Google pra buscar seus leads e diagnosticar sites lentos. Leva uns 5 minutos e é de graça pro uso da Consultoria. Aqui está o passo a passo, o medo do cartão resolvido e a solução dos erros que mais pegam a turma.

O medo do cartão de crédito, resolvido

  • O Google pede um cartão só pra ativar o faturamento da conta. É padrão, não é golpe.
  • Ele não cobra na hora. Você ganha um crédito de cortesia e ainda tem uma cota grátis todo mês.
  • O uso do Orion fica tranquilamente dentro do grátis. Você não faz nem perto de mil consultas por mês. Na prática, não paga nada.
  • Não tem cartão de crédito? Funciona com débito, ou peça ao banco um cartão virtual com saldo zerado só pra o cadastro.
  • E mesmo que passasse do limite: fechou um cliente com a ferramenta, ela já se pagou muitas vezes.

Cadastra o cartão sem medo. É pra liberar o acesso, não pra cobrar.

Abrir o Orion

Passo a passo

A chave dá acesso a duas APIs: Places API (New) (busca os negócios) e PageSpeed Insights (diagnóstico de site lento). Faça na ordem.

Entre no Google Cloud Console

Acesse console.cloud.google.com e faça login com sua conta Google (seu Gmail normal já serve).

Crie um projeto

No topo, clique no seletor de projetos e em "Novo projeto". Dê um nome (ex.: orion-leads), crie e selecione esse projeto.

Ative o faturamento (billing)

No menu, vá em Faturamento e vincule uma forma de pagamento (o cartão de que falamos acima). Sem isso, a busca não funciona. Lembre: é só pra liberar, não cobra.

Ative as 2 APIs que o Orion usa

Com o projeto certo selecionado, abra cada link e clique em "Ativar":

• Places API (New): console.cloud.google.com/apis/library/places.googleapis.com
• PageSpeed Insights API: console.cloud.google.com/apis/library/pagespeedonline.googleapis.com

É a Places API (New), a versão nova. Ative exatamente essa.

Crie a chave de API

Vá em APIs e serviços › Credenciais › Criar credenciais › Chave de API. O Google gera um código comprido: essa é a sua chave. Copie e guarde.

(Opcional) Restrinja a chave com cuidado

Se quiser restringir, em Restrições de API marque as duas: Places API (New) e PageSpeed Insights. Se esquecer uma, o Orion quebra.

Na dúvida, deixe sem restrição pra testar, e restrinja depois que estiver funcionando.

Cole no Orion e teste

Abra o Orion, vá na configuração da chave, cole e clique em testar. Passou? Já pode buscar seus primeiros leads e sair da aula com abordagens enviadas.

Deu erro? Os 4 mais comuns

"Serviço negado" / REQUEST_DENIED

A API não foi ativada, ou o faturamento não está ligado. Confirme os passos 3 e 4 (as duas APIs ativadas + faturamento vinculado), espere 2 ou 3 minutos e teste de novo.

A chave nova não funciona na hora

A ativação leva alguns minutos pra propagar no Google. Espere um pouco e teste de novo. Muita gente resolveu só tentando pela segunda vez.

Continua dando erro de permissão

Confira se ativou a Places API (New) (a nova), e não a antiga. Ative a nova e teste de novo.

Restrições bloqueando

Se você restringiu a chave, garanta que as duas APIs estão nas permitidas. Se restringiu por site/IP, remova a restrição pra testar.

Ainda travou? Manda um print do erro no grupo. A gente destrava rápido.
